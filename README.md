# Caffeine

Coffee brings us together

Static website for Caffeine with About, menu cards, and an interactive sample shop in SGD and HKD.

## Publish

GitHub Pages serves the root of the main branch. No build step is required.

## Shop

Prices are illustrative. The shopping bag is stored in the visitor’s browser. Checkout is a preview and does not submit orders or take payments.

## Update

Edit or replace the HTML, CSS, JavaScript, product JSON, and assets, then commit to main. GitHub Pages publishes the updated files.

Photos and concept footage are illustrative. Credits are included in the website pages.
